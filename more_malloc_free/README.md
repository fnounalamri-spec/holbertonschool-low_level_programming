# 0x0b. C - More malloc, free

Project about dynamic memory allocation in C using `malloc` and `free`.

## Files

| File | Description |
| --- | --- |
| `main.h` | Header file with function prototypes |
| `0-malloc_checked.c` | `malloc_checked` - allocates memory with malloc, exits with status 98 on failure |
| `1-string_nconcat.c` | `string_nconcat` - concatenates s1 with the first n bytes of s2 |
| `2-calloc.c` | `_calloc` - allocates zeroed memory for an array using malloc |
