# 0x0a. C - malloc, free

Project about dynamic memory allocation in C using `malloc` and `free`.

## Files

| File | Description |
| --- | --- |
| `main.h` | Header file with function prototypes |
| `0-create_array.c` | `create_array` - creates an array of chars initialized with a specific char |
| `1-strdup.c` | `_strdup` - returns a pointer to a newly allocated copy of a string |
| `2-str_concat.c` | `str_concat` - concatenates two strings into newly allocated memory |
| `3-alloc_grid.c` | `alloc_grid` - returns a 2 dimensional grid of integers initialized to 0 |
